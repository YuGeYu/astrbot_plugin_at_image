# 群聊艾特生图

AstrBot 插件：用户在群聊中真实艾特机器人并明确提出画图意图时，调用 OpenAI 兼容的图片生成接口，并将图片发送回群聊。

## 使用

在群聊中发送：

```text
@机器人 画一只戴耳机的猫
```

普通聊天、普通艾特、私聊和只有唤醒词的消息不会触发生图。

## 配置

在 AstrBot 插件配置中设置：

- `api_base`：OpenAI 兼容接口地址，默认 `https://api.llmgw.xyz`
- `api_key`：生图服务密钥，仅填写到 AstrBot 远端配置
- `model`：图片模型，默认 `gpt-image-2-[1.5k]`
- `cooldown_seconds`：单用户冷却时间，默认 60 秒
- `timeout_seconds`：单次请求超时，默认 120 秒
- `allowed_groups`：允许触发的群号列表，留空表示全部群聊
- `send_progress`：是否在生成前发送进度提示

插件不会把 API Key 写入源码、日志或仓库。

## 行为与限制

- 仅响应真实艾特机器人且包含明确的画图意图。
- 同一消息只处理一次，并限制全局同时进行的生图请求为一个。
- 上游图片限制为 10 MB，支持 `b64_json` 和 HTTPS 图片 URL 返回格式。
- 请求开始、响应状态和图片大小会写入不含密钥的插件日志。
